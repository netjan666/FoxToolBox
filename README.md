# 🦊 FoxToolBox

> 多功能 VPS 维护与搭建工具箱 —— 一款开箱即用、分区清晰、彩色交互的 Linux 服务器全能管理脚本

## ✨ 功能亮点

- 🎨 **全新分区彩色菜单**：按系统管理、容器与建站、工具与应用清晰分区，交互友好
- 🚀 **一行命令即刻启动**：自动创建 `k` / `K` 快捷指令，支持在线热更新与本地离线缓存容错
- 🌐 **全能建站与容器管理**：内置 LDNMP 建站套件、SSL 自动续期、反代配置及 40+ 精选 Docker 应用市场
- 🔧 **覆盖运维全场景**：系统清理、BBR 加速、WARP、面板部署、节点搭建、甲骨文云保活、虚拟化开小鸡、综合测评与安全防御（Fail2ban / ClamAV / 内核调优 / TG 预警）

## 🚀 快速安装

**一键运行（短链接版，推荐）：**

```bash
bash <(curl -Ls https://tinyurl.com/23hc2sol)
```

**完整版命令：**

```bash
bash <(curl -Ls https://raw.githubusercontent.com/netjan666/FoxToolBox/main/fox_toolbox.sh)
```

**首次运行后**，脚本会自动在系统中创建快捷命令 `k`（自带离线缓存），以后只需：

```bash
k
```

## 📖 使用说明

### 快捷命令

| 命令 | 说明 |
|:---:|:---|
| `k` | 一键启动 FoxToolBox（优先获取最新版，断网自动回退本地缓存） |
| `K` | 同款大写版 |

### 自定义别名（可选）

想用更顺口的名字，在 `~/.bashrc` 中添加：

```bash
alias fox='bash <(curl -Ls https://tinyurl.com/23hc2sol)'
```

然后执行 `source ~/.bashrc`，之后输入 `fox` 即可。

## 🔄 更新方式

每次通过 `k` 启动都会自动检查并拉取 GitHub 最新版脚本，也可以在主菜单输入 `00` 或执行以下命令手动强制更新：

```bash
bash <(curl -Ls https://raw.githubusercontent.com/netjan666/FoxToolBox/main/fox_toolbox.sh)
```
